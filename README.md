# 应用发布仓库

本仓库仅存放个人开发应用的可执行安装包，不含源码。

## 下载

| 应用 | 版本 | 平台 | 下载 |
|------|------|------|------|
| my-notes | v0.3.0 | Windows x64 | [下载](https://github.com/yg-hunter/app-releases/releases/download/v0.3.0-my-notes/my-notes-windows-x64.zip) |
| my-notes | v0.3.0 | Android arm64 | [下载](https://github.com/yg-hunter/app-releases/releases/download/v0.3.0-my-notes/app-release.apk) |

## 使用说明

- **Windows**：下载 zip 解压后直接运行 `my_notes.exe`，无需安装
- **Android**：下载 APK 后安装，需开启"允许未知来源应用"
